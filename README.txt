WINGSPAN HOLIDAYS WEBSITE
==========================

Files:
- index.html
- style.css
- script.js

How to use:
1. Keep all three files in the same folder.
2. Open index.html in a browser.
3. Upload the folder to any static web host.

Notes:
- Built only with HTML, CSS and JavaScript.
- The destination cards use remote Unsplash images, so internet access is needed for those images.
- Contact buttons are linked to phone, email, Instagram and WhatsApp.
- Replace the image URLs in style.css if you want to use your own destination photographs.
